PortfolioHub - Original source files

1. Keep all files in the same folder.
2. Open this folder in Visual Studio Code.
3. Open index.html in your browser (or use Live Server).
4. Admin demo credentials configured in script.js: admin@portfolio.com / admin123.

This is a frontend-only HTML, CSS and JavaScript project using browser Local Storage.
Uploaded images are stored in browser Local Storage as compressed data URLs.
